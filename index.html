About the Project

The Metro Ticket Booking System is a cloud-based web application developed using AWS Serverless Architecture. It enables passengers to register, log in securely, book metro tickets, and access their booking history through a personalized dashboard. The project integrates Amazon S3 for website hosting, Amazon API Gateway for REST APIs, AWS Lambda for backend processing, and Amazon DynamoDB for secure ticket storage. The application eliminates the need for traditional servers while providing scalability, security, and high availability.
